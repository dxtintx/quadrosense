# Проверка 2026-11-13

Билд: 2.1.0, SHA-256 из manifest.json. Контроллер: DualSense USB.

Подтверждено на живом процессе:

- FNamePool RVA 0x9444800; UWorld RVA 0x95C4A68.
- Цепочка UWorld → GameInstance → LocalPlayers[0] → PlayerController → FlyingPawn_C.
- g_Health (+0x764): 100 при поиске, 97.4 при записи телеметрии.
- rawThrustInput (+0xA20): +1 на газе, -1 на тормозе, 0 после отпускания.
- Скорость (+0x728), угловые скорости (+0x730/+0x72C) реагируют на манёвр.
- Минутный запуск `--live-test`: регистрация Mod API, HTTP-запросы приняты,
  итоговый счётчик QuadroSense 2772 HID-отчёта, регистрация удалена по завершении.
- 11 проверок `--self-test` прошли. API и адаптер собираются.

Число HID-отчётов включает периодическое обновление output service и не является
числом кадров игры. Пользователь подтвердил цвет, вибрацию и сопротивление триггеров.
Газ/тормоз потребовалось переназначить с бамперов на R2/L2 в настройках игры.

Ещё проверить: захват по HUD, входящая ракета, потеря HP/вспышки, пауза, главное меню,
смена самолёта/миссии, смерть, повторный вылет, перезапуск процесса, авария адаптера,
отключение/подключение геймпада. `enabled` оставлен false до этих проверок.

Перегрузка вычисляется приближённо. Гироскопическое прицеливание исключено из текущего
объёма по пожеланию пользователя; реализация не требуется для первой версии.
Обычный QuadroSense.exe из dist нужно пересобрать для применения исправления TTL.

## Вторая сессия

- Пользователь подтвердил выключение подсветки в паузе и включение в полёте.
- Найдена ошибка интерпретации m_LockedOn: 153 записи совпадали с собственным
  захватом цели. Из-за приоритета warning подсветка была красной вместо оранжевой.
- Источник warning заменён на число элементов MissileRefCollection (+0x968).
  После исправления зафиксированы состояния TargetLocked=true / MissileWarning=false.
  Пользователь подтвердил оранжевый цвет после исправления. Входящая ракета
  не воспроизведена: подтверждения по HUD пока нет.
- Зафиксировано изменение HP с 97.4 до 96.1 во второй сессии. Это активирует эффект
  урона; пользователь подтвердил красные вспышки при потере HP. Позднее HP достигли 94.8%.
- Добавлена проверка FlyingPawn_C по FNamePool/иерархии классов перед чтением полей.

## Низкая скорость и торможение

- В состояние добавлена скорость в км/ч (из cm/s умножением на 0.036).
- Добавлена лёгкая фоновая вибрация и тяжёлая вибрация от замедления при торможении.
- 18 self-test проверок прошли, включая отсутствие ложного эффекта после паузы,
  разрыва телеметрии, при потере скорости без тормоза и затухание на постоянной скорости.
- Ощущения новых эффектов на устройстве ещё требуют проверки пользователем.
- Входящая ракета повторно не воспроизведена; источник warning остаётся непроверенным.

Уточнение скоростной кривой: лёгкая вибрация при взлёте/малой скорости затихает
к 350 км/ч. Включительно от 350 до 700 км/ч газ не вызывает вибрацию. Выше 700
она плавно возвращается пропорционально газу. Урон, перегрузка и торможение независимы.
Добавлены проверки границ спокойного диапазона, взлёта, роста эффекта выше 700
и сохранения торможения/перегрузки внутри диапазона. Проверка ощущений ещё предстоит.

Для триггеров добавлена скоростная кривая: тормоз 2→8, газ 8→2 в диапазоне
150–1000 км/ч. Self-test проверяет взлёт, середину крейсерского диапазона и высокую
скорость.
